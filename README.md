# Quick-Game-UnitTests

A lightweight C# unit testing project demonstrating automated game logic validation using NUnit. Designed for QA Automation portfolio showcase.

## Features Tested
- **Score Management**: Ensures scores increment correctly with valid positive inputs.
- **Health & Damage Logic**: Validates boundary conditions (Edge Cases), ensuring health values never drop below zero.

## Tech Stack
- **Language**: C#
- **Testing Framework**: NUnit# Quick-Game-UnitTests
